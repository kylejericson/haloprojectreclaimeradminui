# Security policy

Reclaimer Control can edit server configuration and send player moderation commands. Run it only on a trusted host and network, use a unique strong `ADMIN_PASSWORD`, and do not expose the panel or unencrypted RCON to the public internet.

For a security issue, do not open a public issue containing exploit details. Contact the maintainer privately through the repository hosting provider's private vulnerability-reporting channel. If that channel is unavailable, ask a maintainer for a private contact route without posting sensitive details publicly.

Supported versions: the latest published source. Please include the Reclaimer Control revision, deployment type, and relevant redacted logs in a report. Never include passwords, cookies, player IDs, or public IPs unless essential.
